# ⚖️ Judge Dredd Discord Bot

Discord-бот для автоматизированных публичных судебных заседаний с вердиктами от нейросети **Google Gemini**.

---

## 🎯 Как это работает

1. **Подача жалоб по статьям:**
   * Пользователи сервера могут подавать жалобы по 3 категориям:
     * ☣️ **Токсичность** (оскорбления, агрессия, травля, провокации)
     * 📢 **Дебош** (спам, флуд, крики в голосовых каналах, помехи общению)
     * 💣 **Вредительство** (спойлеры, слив закрытой информации, порча игр или ивентов)
   * Команда: `/report user:@гражданин category:статья reason:причина` либо через контекстное меню (ПКМ по пользователю -> *Apps* -> *Подать жалобу в суд* с интерактивным выбором статьи).
   * Защита от накрутки: один пользователь не может подать несколько активных жалоб на одного и того же человека по одной статье.
2. **Инициация суда по конкретной статье:**
   * Когда на пользователя накапливается необходимое количество жалоб ($X$, по умолчанию `3`) **в рамках одной статьи**, бот запускает процесс именно по этой категории.
   * Судебный зал получает тематическое название (например, `дело-1-токсичность`). Обвиняемый защищается от конкретного состава нарушения, а ИИ оценивает дело строго в рамках этой статьи.
3. **Публичный судебный зал:**
   * Бот создает текстовый канал `дело-номер-%номер дела%`.
   * Суд **публичный**: весь сервер может читать канал в реальном времени, но писать могут только участники в строго отведенную очередь.
4. **Стенограмма и выступления сторон:**
   * **Слово обвинения:** Бот по очереди вызывает каждого обвинителя к трибуне. На выступление дается таймер (настраивается, по умолчанию 3 минуты). Участник может закончить речь раньше кнопкой `Завершить речь ⚖️`.
   * **В дело вступает Адвокат Сол Гудман!** Обвиняемому не нужно отбиваться в одиночку — его интересы представляет легендарный скользкий кибер-адвокат Соломон Гудман (*«Лучше звоните Солу!»*).
   * **Брифинг:** Обвиняемый пишет в чат своими простыми словами, как всё было на самом деле.
   * **Речь Защиты:** Сол Гудман превращает слова подзащитного в пламенную юридическую речь с вымышленными прецедентами, разгромом обвинителей и требованием оправдания.
5. **Вердикт Судьи Дредда (Gemini AI):**
   * Судья Дредд сопоставляет нападки обвинения и виртуозную речь Сола Гудмана.
   * Если обвинители действовали из троллинга или без доказательств — Сол Гудман разваливает дело, и гражданина оправдывают.
   * Если нарушения доказаны — Дредд осаживает адвоката и выносит строгий приговор с цитированием статей вымышленного 500-страничного Кодекса.
6. **Приведение приговора в исполнение и Социальный Рейтинг:**
   * **Если ВИНОВЕН (Рецидив):**
     * Обвиняемый теряет **-150 очков** социального кредита.
     * **Штраф за рецидив:** срок тайм-аута умножается в зависимости от прошлых судимостей (+50% за каждый прошлый приговор).
     * Обвинители получают **+50 очков** за проявленную бдительность.
   * **Если ОПРАВДАН (Клевета / Ложный донос):**
     * Обвиняемый получает **+100 очков** социального кредита в качестве моральной компенсации.
     * Обвинители штрафуются на **-100 очков** каждый по статье о ложном доносе.
   * Через 10 минут канал закрывается и архивируется.

## 🐳 Запуск через Docker

Бот полностью подготовлен для работы в изолированном Docker-контейнере. База данных сохраняется в папке `./data` на вашем диске, поэтому при перезапусках контейнера история дел и жалобы не пропадут.

### Быстрый запуск в 1 клик (Windows):
* **Запустить / пересобрать:** запустите **`docker_start.bat`**
* **Посмотреть логи:** запустите **`docker_logs.bat`**
* **Остановить:** запустите **`docker_stop.bat`**

### Либо вручную через консоль:
```bash
# 1. Собрать и запустить контейнер в фоне
docker-compose up -d --build

# 2. Посмотреть логи в реальном времени
docker-compose logs -f

# 3. Остановить контейнер
docker-compose down
```

## 🚀 Быстрый старт (без Docker)

### 1. Требования
* Python 3.10 или новее.
* Discord Bot Token (создается на [Discord Developer Portal](https://discord.com/developers/applications)).
* Google Gemini API Key (получить бесплатно на [Google AI Studio](https://aistudio.google.com/)).

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` на основе `.env.example`:
```ini
DISCORD_TOKEN=ваш_токен_бота
GEMINI_API_KEY=ваш_ключ_gemini_api
DEV_GUILD_ID=123456789012345678  # Необязательно: ID вашего тестового сервера для мгновенной регистрации слэш-команд
```

### 4. Настройка прав бота в Discord Developer Portal
1. Перейдите во вкладку **Bot** в панели разработчика Discord.
2. Включите **Privileged Gateway Intents**:
   * ✅ **Server Members Intent** (нужен для управления участниками и наложения таймаутов)
   * ✅ **Message Content Intent** (нужен для чтения стенограммы речей в судебном зале)
3. Пригласите бота на сервер с правами:
   * `Manage Channels` (Создание и удаление залов суда)
   * `Manage Roles / Timeout Members` (Наложение наказаний)
   * `Send Messages / Embed Links`
   * `Manage Permissions`

### 5. Запуск
```bash
python main.py
```

## 🛠️ Команды бота

### Для пользователей:
* `/report <пользователь> <причина>` — подать жалобу.
* Контекстное меню пользователя (ПКМ -> Apps) -> **Подать жалобу в суд** — открывает форму для жалобы.
* `/dossier <пользователь>` — посмотреть досье и количество активных жалоб на гражданина.

### Для администрации:
* `/judge-config threshold <X>` — изменить необходимое количество жалоб для запуска суда (например, `5`).
* `/judge-config speech_time <секунды>` — изменить время на выступление каждой стороны (от 30 до 600 секунд).
* `/judge-config category <категория>` — назначить категорию, где будут открываться залы суда.
* `/judge-config view` — просмотреть текущие настройки сервера.
